# whoami — Alen Thomas Portfolio

A personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Live Site

- https://alenthomas4.github.io/whoami/

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Typed.js
- GitHub Pages (`gh-pages`)

## Project Structure

```text
whoami/
├── client/                 # Frontend portfolio app
│   ├── public/             # Static assets
│   ├── src/                # Components, pages, styles
│   ├── vite.config.ts
│   └── package.json
├── package.json            # Workspace/root scripts
└── README.md
```
